# 本地控制台

本页描述 Legacy 模式的状态总览、首次设置、连接指南和诊断；原托盘入口仍保留。它调用原有产品接口，不替代外部运行时。新增 Sunshine 模式提供独立引导及只读检查，使用步骤见 [Sunshine 首次使用](sunshine-quickstart.md)。

## 打开界面

在完整源码目录双击根目录的 `Start-GsController.cmd`。启动器会打开 `product/gs-console.vbs`，由 Windows 请求管理员确认，并在默认浏览器打开本机控制台。默认地址为 `http://127.0.0.1:47991`。

控制台使用 Windows PowerShell 5.1、系统 .NET 和浏览器，不需要安装 Node.js、前端包管理器或额外 Web 框架。HttpListener 权限不足时会明确失败，不会替你添加 URL ACL、服务或防火墙规则。

通过启动器打开时，已在运行、监听失败、配置初始化失败或系统不受支持会显示固定提示；已在运行时可从托盘重新打开。提示不包含会话链接或原始异常内容。命令行默认保留错误输出和退出码，不弹窗；原生提示窗口仍需实机验收。

浏览器关闭后，可从控制台的托盘菜单重新打开。关闭控制台不会停止已经运行的串流；正在执行操作时应先等待结果。不要分享最初的完整启动链接，正常打开后页面会移除其中的会话片段。

## 先体验演示模式

开发验证使用演示模式，只改变演示状态及临时目录里的控制台配置，不调用真实运行时或系统任务：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\product\gs-console.ps1 -Demo -Port 47992
```

此示例使用47992，避免占用正式入口默认的47991。`-ExecutionPolicy Bypass` 仅作用于这一进程；如组织策略不允许，应使用获准的启动方式，不要修改机器策略来绕过限制。

演示页始终显示“演示模式”。可查看未配置、已停止、可连接、串流中和错误状态，体验启停、设置保存、检查与诊断流程。演示中显示的设备地址和结果是模拟数据，不能当作本机串流验收。

## 首次设置与日常操作

1. 在设置页选择运行时文件夹、合法自备的组件文件夹。程序、状态和日志目录应互不相同、互不嵌套，来源目录也不能与目标目录重叠。
2. 保存设置只保存控制台的偏好和目标路径，不移动已有文件，不自动部署、启动或注册开机任务。
3. 需要首次部署或更新时，点击部署操作，核对确认框中的目标目录。部署调用现有 catalog 与 Install 流程；实际使用前必须具备合法兼容的依赖。
4. 部署和检查完成后，在总览点击启动。停止、恢复或更改开机自启时，先阅读确认提示。停止可能需要约两分钟，界面会显示进行中；不要反复点击。
5. 已配对客户端可按连接指南在 Moonlight 中添加电脑地址。首次配对需要主机端确认入口，当前产品尚未提供；缺少该入口时先停止配对尝试，详见 [首次配对交付条件](first-pairing-readiness.md)。分辨率、帧率和码率由客户端设置；本控制台不提供未经公开接口支持的主机编码参数。

显示名称只改变控制台中的名称，不会重命名 Windows 电脑或运行时的网络名称。已部署实例的日常启停不要求原始来源文件夹一直存在；这些目录用于再次部署。控制台设置与产品的 runtime-config.json 分开管理，保存偏好不直接覆盖后者。

若操作在写任务文件或启动执行进程时失败，会记录失败并解除忙态；可在解决目录写入或进程启动问题后重试。对于已经启动但尚未确认退出的执行进程，控制台仍保持忙态，避免并发执行。

## 诊断与支持

诊断页按需运行检查，并展示受限、可读的摘要。可复制或下载这个摘要。它不展示原始运行时输出、完整日志、证书、PIN 或配对记录。

完整支持 ZIP 仍使用既有的普通权限支持工具；控制台不会从提权的 Web 服务调用该工具。真实运行时安装、配对和设备验收仍遵守产品的原有要求。

## 本机访问与安全边界

- 仅接受回环来源与预期 Host，拒绝跨来源修改请求；没有开放局域网管理入口。
- 每次控制台进程有独立的临时会话，API 检查会话请求头；不通过匿名 API 返回该会话值，也不将其写入配置或日志。
- 操作采用固定白名单，网页不能指定要执行的脚本或任意 PowerShell 命令。
- 请求体、输入长度与操作时间有界；设置更改和长操作互斥。真实动作只在用户明确操作后执行，演示模式不会调用它们。
- 浏览器界面不会创建 URL ACL、修改防火墙或自动开放远程访问。当前版本不提供多用户远程管理，也不以本机 Web 会话替代 Windows 权限边界。

## 验证状态

本页对应本地控制台开发分支。已在 TEMP 与假 CLI 上验证接口，并用实际 PowerShell 服务的 Demo 模式检查浏览器界面：启停与确认取消、保存及刷新保留、运行中目标目录只读、中文诊断摘要、配置版本冲突拒绝、桌面与窄屏布局。演示及测试均未调用用户的真实运行时。

真实 UAC 启动器、托盘菜单、原生目录选择窗口和实际运行时部署/启停/自启仍需对应环境验收；不把 Demo 结果表述为这些操作已验证。Web API 仅允许明确的 `127.0.0.1` 与 `localhost` 两个回环别名，同时校验实际远端地址，不能通过改 Host 获得局域网访问。
